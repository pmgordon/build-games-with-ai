# AI Talk Games

This repo is for an instructional talk where students (roughly grades 7–13) learn that building with AI can start from almost nothing: a simple idea, a few preferences, and iterative questions.

## How this project is used in the talk

- Start with a plain-language goal (example: “I want to make a brick breaker game in a web browser”).
- Let AI ask clarifying questions.
- Answer in your own words.
- Turn those answers into a working game.
- Review the build process so beginners can repeat it.
